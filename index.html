STEP 01

放入更新後的試題檔

將最新週次的 .docx、.pdf 或 .md 放進對應資料夾：sources/chinese/、sources/math/、sources/social/。若有本地圖檔，直接放入各科的 images/ 資料夾。

STEP 02

一鍵同步題庫資料

雙擊專案目錄中的 update.command，或在終端機執行 python3 scripts/build_data.py，系統會自動解析所有週次、擷取 PDF 配圖並輸出最新 JSON 至 data/。

STEP 03

推送至 GitHub 自動發布

執行 git push（或直接在 GitHub 網頁版上傳更新檔），內建的 GitHub Actions 工作流程將自動重新解析並更新 GitHub Pages 線上網站。
