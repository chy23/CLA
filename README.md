# 115學年-1 課堂形成性評量網站（國語・數學・社會）

專為國小高年級課堂投影與形成性評量設計的靜態多頁面教學系統。教師只需每週將更新後的 `.docx`、`.pdf` 或 `.md` 試題檔案放入對應科目資料夾，執行一鍵更新腳本（或推送至 GitHub），網站即自動同步最新週次與題目。

## 網站頁面架構

| 頁面 | 路徑 | 說明 |
| --- | --- | --- |
| 總覽首頁 | `index.html` | 三科快速入口、各週進度矩陣與更新指南 |
| 國語講台 | `chinese.html` | 翰林版 · 情境閱讀雙欄投影、字詞句型、插圖燈箱與評分規準 |
| 數學講台 | `math.html` | 康軒版 · 是非／選擇／應用題、KaTeX 公式排版與逐行算式步驟演示 |
| 社會講台 | `social.html` | 南一版 · 時事與史料圖表、立場思辨雙欄卡與分層評分規準 |

## 課堂形成性評量功能

- **雙檢視模式**：
  - **講台逐題模式（預設）**：單題聚焦呈現，含題組閱讀或配圖時自動切換為左右雙欄（左欄固定參考資料、右欄互動答題），答案與解析預設隱藏不暴雷。
  - **試卷總覽模式**：一次檢視全週試題，支援單題／全週展開答案，並提供「列印空白學習單（學生版）」與「列印教師解答卷」。
- **互動答題與刪去法**：點擊選項標記班級討論焦點，點擊 `✕ 刪去` 劃除干擾選項；是非題配備大型 `○ 正確` / `✕ 錯誤` 觸控按鈕。
- **分層揭曉答案簾**：第一層揭曉正確答案（數學應用題支援逐步顯示算式步驟），第二層展開詳細解析與評分規準。
- **隨手課堂教具**：思考倒數計時器（含提示鈴聲）、班級不重複隨機抽號器、觸控大屏板書畫筆標記、圖片放大燈箱、三段投影字級（標準／大字／特大）。

### 鍵盤快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `←` / `→` | 上一題 / 下一題 |
| `Space` | 分層揭曉答案 / 顯示下一步算式 |
| `E` | 直接展開或收合詳細解析與評分規準 |
| `1`～`4` | 標記選項 (A)～(D)（是非題：`1`=○、`2`=✕） |
| `T` | 開啟／關閉思考計時器 |
| `R` | 開啟／關閉班級隨機抽號器 |
| `B` | 開啟／關閉板書畫筆 |
| `F` | 切換全螢幕投影 |
| `?` | 顯示快捷鍵說明 |

## 每週更新試題的三個步驟

1. **放入最新試題檔**（覆蓋舊檔或新增分週檔皆可，檔名以 `_` 開頭的範本檔會被自動略過）：
   - 國語：`sources/chinese/`（支援 `.pdf` / `.docx` / `.md`）
   - 數學：`sources/math/`（支援 `.docx` / `.pdf` / `.md`）
   - 社會：`sources/social/`（支援 `.docx` / `.pdf` / `.md`）
2. **執行轉換腳本**：
   - macOS 使用者直接雙擊專案根目錄的 **`update.command`**；或於終端機執行：
     ```bash
     python3 scripts/build_data.py
     ```
   - 腳本會自動解析所有週次、從 PDF/DOCX 內嵌媒體擷取插圖，並更新 `data/chinese.json`、`data/math.json`、`data/social.json` 與 `data/manifest.json`。
3. **本機預覽或推送至 GitHub**：
   - 本機預覽：
     ```bash
     python3 -m http.server 8765
     ```
     瀏覽器開啟 `http://127.0.0.1:8765/`。
   - 推送更新：`git add . && git commit -m "更新第 XX 週試題" && git push`（亦可直接在 GitHub 網頁版上傳檔案至 `sources/`，`.github/workflows/deploy.yml` 會自動重新建置並發布至 GitHub Pages）。

### 雲端配圖轉為本地直出（社會科／數學科）

若 DOCX 中的配圖原本是以私人 Google Drive 超連結提供，講台會自動以「檔案圖表卡」呈現圖名、查證說明與「開啟雲端原圖 ↗」按鈕（絕不出現破圖）。
若希望上課時**免登入 Google 直接在講台內嵌顯示圖片並可放大檢視**，只需將圖檔放入對應資料夾並執行 `update.command`：
- 社會科放入 `sources/social/images/`，檔名可為完整圖名（如 `第11週_圖一_戰後土地改革進程示意圖.png`）或簡稱 `w11_fig1.png`
- 數學科放入 `sources/math/images/`，檔名可為完整圖名（如 `第十一週_第7題_台北101風阻尼球示意圖.png`）或簡稱 `w11_q7.png`

## GitHub Pages 啟用方式

1. 前往 GitHub 倉庫的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 推送至 `main` 分支後即可於 `https://chy23.github.io/CLA/` 開啟使用。
